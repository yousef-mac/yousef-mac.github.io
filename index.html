V10 TerminalDesktop trading terminal

Trading software built for the desktop.

V10 Terminal is a desktop application for charting, market analysis and trade management. It connects only to the trading account its user explicitly authorises, and only with that user's consent.

About

V10 Terminal is a client application. It does not hold customer funds, does not act as a broker, and does not provide investment advice. All trading accounts remain held and serviced by the regulated broker the user chooses.

The application connects to a user's own account through the account provider's official API, using a standard authorisation flow that the user approves and can revoke at any time.

What it does

  • Displays live price charts and historical market data
  • Shows account information the user has authorised access to
  • Lets the user place, modify and close their own trades
  • Keeps the user in control: no trade is sent without a direct action by the account holder
